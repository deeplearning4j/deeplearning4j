## Investigation Findings: Causal Mask Not Updated Per Step in Frozen Decode Path

### Bug Identified: Stale Causal Mask in `reusableInputs` Cache

**Location:** `DecoderUtils.java:737-746` (causal mask path in `buildDecoderInputMap`)

```java
} else if (ioConfig.isCausalMask(inputName)) {
    if (usePadded) {
        // Padded mode: causal mask matches concat shape (maxKvLen + currentSeqLen)
        if (canReuse && reusableInputs.containsKey(inputName)) {
            decoderInputMap.put(inputName, reusableInputs.get(inputName));  // ← BUG: mask content NEVER updated
        } else {
            long totalSeqLen = maxKvLen + currentSeqLen;
            INDArray causalMask = buildCausalMask(currentSeqLen, totalSeqLen);
            decoderInputMap.put(inputName, causalMask);
            if (canReuse) reusableInputs.put(inputName, causalMask);
        }
    }
```

**The bug:** When `usePadded=true` (frozen shapes, `dspActive && usingStaticKv`) and `canReuse=true` (`reusableInputs != null && usingStaticKv && currentSeqLen == 1`), the causal mask is **built ONCE** at step 1 (the first decode step after prefill), cached in `reusableInputs`, and then **returned verbatim for every subsequent step** — the mask content is never modified.

### Why This Causes Degeneration

The causal mask built at step 1 has `currentSeqLen=1` and `totalSeqLen=maxKvLen+1`. For `currentSeqLen=1`, `buildCausalMask` returns **all zeros** (line 83-84):

```java
public static INDArray buildCausalMask(long currentSeqLen, long totalSeqLen) {
    if (currentSeqLen == 1) {
        return Nd4j.zeros(DataType.FLOAT, batchSize, 1, 1, totalSeqLen);  // ALL zeros
    }
```

So the step-1 mask is `[1, 1, 1, maxKvLen+1]` filled entirely with `0.0` — meaning the single decode token attends to ALL positions including future (unwritten) positions. That happens to be correct for step 1 because `cachePos=prefillSeqLen` and all positions `[0..prefillSeqLen)` already contain valid KV data.

But at step 2, 3, 4... the mask is **the same all-zeros array**. The model should NOT attend to positions beyond `cachePos` (which are still zeros from padding), but the mask allows it. The model reads garbage (zero-padded) KV positions, corrupting attention output.

### Contrast: `attn_mask_reformat` Override IS Updated Correctly

The `attn_mask_reformat` placeholder override path (lines 813-847) does update the mask content per-step:

```java
if (canReuse && reusableInputs.containsKey(inputName)) {
    INDArray bias = reusableInputs.get(inputName);
    // Unmask ALL positions [0, cachePos) — not just cachePos-1.
    if (cachePos > 0) {
        for (int p = 0; p < (int) cachePos; p++) {
            bias.putScalar(new long[]{0, 0, 0, p}, 0.0f);  // ← Updates per step
        }
    }
    decoderInputMap.put(inputName, bias);
}
```

But the plain `_causal_mask` / attention mask path does NOT have an equivalent per-step update — it just returns the stale array.

### Why `--no-freeze` Works

When `--no-freeze` is passed (`nd4j.dsp.noFreeze=true`):

1. **`skipFreeze=true`** (`StaticKvCacheDecodeLoop.java:339`)
2. **DSP is disabled** (`StaticKvCacheDecodeLoop.java:663-664`): `decoder.setDspAutoCompileEnabled(false)`
3. **`dspActive`** is still `usingStaticKv && !noPadded` — but with `noFreeze`, the `noPadded` property is typically also set (they often go together in benchmark configs). If `dspActive=false`, then `usePadded=false`, which means the `usePadded` branch is NOT taken.
4. Instead, the **`else if (usingStaticKv)` view-based path** is taken (line 747-750):
   ```java
   } else if (usingStaticKv) {
       long totalSeqLen = cachePos + currentSeqLen;
       INDArray causalMask = buildCausalMask(currentSeqLen, totalSeqLen);  // ← Rebuilt every step
       decoderInputMap.put(inputName, causalMask);
   }
   ```
   This path **rebuilds** the mask from scratch every step with the correct `totalSeqLen = cachePos + currentSeqLen`, so the mask is always correct.

Even if `dspActive=true` in no-freeze mode, the DSP plan is recompiled every step (or not used at all), so the stale mask may be re-ingested each time from the feed map.

### Additional: `attention_mask` (not `_causal_mask`) IS Updated Correctly

The regular `attention_mask` path (lines 699-726) correctly updates per-step:
```java
if (canReuse && reusableInputs.containsKey(inputName)) {

    if (cachePos > 0) {
```

### Proposed Fix

In `DecoderUtils.java` lines 737-746, the causal mask reuse path needs to update the content per-step, similar to how `attn_mask_reformat` does it. Since `currentSeqLen=1` during decode, the mask is shape `[1, 1, 1, maxKvLen+1]` and only position `[0,0,0,cachePos]` onward needs masking. The fix should set `[0:cachePos)` to `0.0` and `[cachePos:maxKvLen]` to `MASK_FILL`:

```java
if (canReuse && reusableInputs.containsKey(inputName)) {
    INDArray causalMask = reusableInputs.get(inputName);
    // Update mask content for current step: positions [0..cachePos-1] are valid,
    // [cachePos..maxKvLen-1] are padded (must be masked).
    for (int k = (int) cachePos; k < (int) maxKvLen; k++) {
        causalMask.putScalar(new long[]{0, 0, 0, k}, MASK_FILL);
    }
    decoderInputMap.put(inputName, causalMask);
}
```

Or more efficiently, zero the entire mask first then fill masked positions:
```java
if (canReuse && reusableInputs.containsKey(inputName)) {
    INDArray causalMask = reusableInputs.get(inputName);
    causalMask.assign(0.0f);  // Unmask all
    for (int k = (int) cachePos; k < (int) maxKvLen; k++) {
        causalMask.putScalar(new long[]{0, 0, 0, k}, MASK_FILL);
    }
    decoderInputMap.put(inputName, causalMask);
}
```
